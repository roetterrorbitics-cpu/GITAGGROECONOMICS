# Peach app logo

The app logo is available at [`assets/logo-peach.svg`](assets/logo-peach.svg).

It uses a soft, premium consumer-tech treatment: a warm rounded-square app tile, a sculpted peach, and a restrained green leaf. The SVG is resolution-independent and includes an accessible title and description.
